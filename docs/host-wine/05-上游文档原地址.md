## D. 来源更新规则

每次开始一个新阶段时：

1. 记录两个上游 `main` 的最新 commit；
2. 对比固定基线；
3. 把影响当前实现的变化写入 `CHANGELOG.md` 和实施日志；
4. 不静默切换上游版本；
5. 若采用新的 PalOps 文件作为参考，必须补充到 `04-PalOps功能与参考文件映射.md`。
