# 测试与验收

## 1. 测试层级

| 层级 | 范围 |
|---|---|
| 单元测试 | Runtime 状态机、PID 身份、下载器、路径校验、配置校验、权限和审计 |
| 集成测试 | Go API + SQLite + fake runner + fake REST/RCON/PalDefender |
| 前端测试 | 权限路由、任务状态、错误降级、移动端 |
| 脚本测试 | Bash 语法、heredoc、环境探测、版本升级和回滚 |
| 实机测试 | 简幻欢 Linux + NFS + Wine 11.13 + Windows PalServer |
| 长期测试 | 24/72 小时运行、定时保存、重启、Workshop、侧车恢复 |

## 2. Phase 1 必过场景

### Host-Wine Runtime

- 已停止、启动中、健康、降级、停止中、崩溃、熔断状态正确。
- 后端重启后能重新识别当前 PalServer。
- PID 重用、错误 WINEPREFIX、仅 wineserver 存在时不误判。
- 启动参数包含面板参数并去重固定参数。
- 面板启动失败不会杀死已运行的 PalServer。

### 停服和保存

- 先请求保存并确认完成，再正常关服。
- 正常关服失败后才发送 INT/TERM/KILL。
- `.new_tmp`/manifest 事务未完成时不强制宣布安全停止。
- 手动停服不触发崩溃守护。

### NFS SaveGames

- Linux `os.replace` 探测通过。
- Wine `move /Y` 探测通过。
- Prepared 事务文件大小不符时拒绝恢复。
- Prepared 恢复前生成备份。
- 活动目录是实际目录而非 symlink/mount/shm 镜像。
- sav-cli 只有读权限/只读语义。

### Windows SteamCMD

- 服务端安装、validate、BuildID 获取正常。
- Workshop 在服务器运行时下载，不等待服务器前缀 wineserver。
- anonymous 成功。
- anonymous 失败且有缓存账号时回退。
- 未配置账号时不执行账号探测。
- Steam Guard 阻塞返回 `blocked`，不永久挂起。
- 180 秒无活动返回 `stalled`。
- 下载成功后才创建最终 inspection 目录。
- 失败不会留下可安装的半成品目录。

### GitHub 代理

- 主代理成功。
- 主代理失败后备用成功。
- 两个代理失败后直连成功。
- 三者失败返回明确错误。
- HTML 错误页不能通过 tar/zip 校验。
- SHA 错误删除缓存并重试。
- 重定向不能绕过私有地址/凭据保护。

### PalDefender/UE4SS

- GitHub Release API 403 时本地状态页仍能完成加载。
- Release 下载、SHA、备份和回滚正常。
- UE4SS 仅存在一个实际运行版本。
- 加载状态只来自真实日志/marker。
- 启动脚本和面板不能并发修改 Mod 文件。

### 升级/回滚

- 从 v1.0.36 部署升级。
- 数据库迁移前有备份。
- 新面板健康检查失败时恢复旧版本。
- 配置、数据库、存档、Mod、Wine 前缀保持不变。
- 旧脚本可按文档恢复。

## 3. Phase 2/3 安全验收

- Viewer 无法调用写 API。
- Operator 不能修改 Owner/管理员权限。
- Auditor 可读审计但不能执行玩家操作。
- CSRF、同源和会话检查在后端执行。
- RCON 高危命令必须确认并写审计。
- 批量操作每个玩家都有结果和幂等保护。
- 白名单/封禁文件 SHA 冲突返回 409 类错误，不覆盖外部修改。
- Webhook 防 SSRF，不跟随到私有/回环地址；凭据不进日志。
- 崩溃守护达到阈值后熔断，手动解除有审计。
- 存档差异读取快照，不持有活动存档写句柄。

## 4. 性能和稳定性

- `docker stats` 模拟删除后，Host-Wine 指标采集不得每秒扫描整个文件系统。
- `/proc` 采集有时间上限和缓存。
- sav-cli 索引失败保留最后成功缓存。
- NFS 上 SQLite 使用经过验证的 journal/synchronous/busy timeout 设置。
- 审计、统计、日志和通知历史有保留策略。
- 72 小时运行无 PID 泄漏、孤儿 Xvfb/侧车和无限日志增长。
