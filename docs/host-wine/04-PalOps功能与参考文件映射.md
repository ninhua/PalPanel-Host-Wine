# PalOps 功能与参考文件映射

## 1. 使用规则

PalOps Web 使用 .NET 10 + Vue 3；PalPanel 使用 Go + React。以下文件用于理解业务边界、状态机、校验、权限和审计，**不是要求逐行翻译或直接复制**。

固定参考快照：`CoderYiXin/PalOpsWeb@b51bd84a76ae0e83442feaa8c6bffc1b97e5d119`（1.2.0）。

总入口：

- [`Program.cs`](https://github.com/CoderYiXin/PalOpsWeb/blob/b51bd84a76ae0e83442feaa8c6bffc1b97e5d119/src/PalOps.Web/Program.cs)：服务注册、授权策略、端点映射、托管服务。
- [`docs/features.md`](https://github.com/CoderYiXin/PalOpsWeb/blob/b51bd84a76ae0e83442feaa8c6bffc1b97e5d119/docs/features.md)：功能、角色、数据来源和行为契约。
- [`docs/architecture.md`](https://github.com/CoderYiXin/PalOpsWeb/blob/b51bd84a76ae0e83442feaa8c6bffc1b97e5d119/docs/architecture.md)：架构和安全边界。

## 4. 参考代码使用边界

- 可以参考状态机、校验顺序、错误分类、接口语义和测试场景。
- 不得声称 PalOps 代码是 PalPanel 原生代码。
- 复制或改编 GPL 代码时，必须保留许可证和来源记录。
- 实现日志中应为每个功能记录：PalOps 参考文件、PalPanel 目标文件、差异和测试。
