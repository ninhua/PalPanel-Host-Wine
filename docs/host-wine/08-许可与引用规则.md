# 许可与引用规则

## 1. 上游许可

PalPanel 与 PalOps Web 均声明使用 GPL-3.0-or-later。实际发布前仍需以目标 commit 中的 LICENSE/NOTICE/第三方声明为准。

## 2. 参考与改编

- 业务设计、接口语义、错误分类和状态机可以作为实现参考。
- 直接复制或实质性改编 PalOps 源码时，必须保留 GPL 义务、版权和来源记录。
- 不复制 PalOps 的品牌、截图资产或编译产物作为 PalPanel 自有内容。
- PalDefender、UE4SS、PalCalc、地图和游戏素材按各自许可处理。

## 3. 代码注释和文档来源

每个借鉴明显的模块在设计文档中记录：

```text
Reference project: CoderYiXin/PalOpsWeb
Reference commit: b51bd84a76ae0e83442feaa8c6bffc1b97e5d119
Reference files: ...
Adaptation: rewritten in Go/React for PalPanel Host-Wine runtime
```

代码注释不需要在每个函数重复来源，但不能删除原有版权声明。

## 4. 发布文件

Release 包应保留：

- PalPanel LICENSE；
- 修改后的源码获取方式；
- THIRD_PARTY_LICENSES/NOTICE；
- 对 PalOps 参考和改编范围的说明；
- PalDefender、UE4SS、PalCalc 等第三方许可。

## 5. 不确定项

许可冲突、素材再分发或商标使用存在疑问时，停止打包该资产，改为运行时从官方来源下载，并在文档中提供原地址和校验方式。
